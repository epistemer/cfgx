# neozp records parked here

These two documents are about neozp as a whole, not about cfgx. They are kept
here because the generation driver they describe has no repository yet, and
cfgx's and i18n's records refer to them.

- [0001-generation-pipeline.md](0001-generation-pipeline.md): neozp ADR 0001,
  one generation pipeline over shared metadata.
- [genx-roadmap.md](genx-roadmap.md): the driver's roadmap. `genx` is a
  working name.

Both move to the driver's repository when it exists (its roadmap item M0.4),
and this folder goes away.
