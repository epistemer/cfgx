# mini configuration

Minimal cfgx example. Generated by cfgx from the schema; don't edit.

Each setting comes from, highest first: a flag, an environment variable, the config file (`mini.yaml`, `.yml` or `.json`, looked for in `.`, `$HOME/.config/mini`, or named by `--config` or `MINI_CONFIG`), or its default. An empty value counts as not set.

## `server`

HTTP server.

| Key | Description | Type | Default | Env | Flag | Used by |
|-----|-------------|------|---------|-----|------|---------|
| `server.host` | Listen host. | string | `localhost` | `MINI_SERVER_HOST` | `--server-host` | Serve |
| `server.port` | Listen port. | int | `8080` | `MINI_SERVER_PORT` | `--server-port` | Serve |
| `server.tls` | Enable TLS. | bool |  | `MINI_SERVER_TLS` | `--server-tls` | Serve |

## `database`

Database connection.

| Key | Description | Type | Default | Env | Flag | Used by |
|-----|-------------|------|---------|-----|------|---------|
| `database.url` | Database connection URL. | string |  | `MINI_DATABASE_URL` | `--database-url` | Serve, Migrate |
| `database.timeout` | Query timeout in seconds. | int |  | `MINI_DATABASE_TIMEOUT` | `--database-timeout` | Serve, Migrate |
| `database.debug` | Log SQL queries. | bool | `false` | `MINI_DATABASE_DEBUG` | `--database-debug` | Serve, Migrate |

## `log`

Logging.

| Key | Description | Type | Default | Env | Flag | Used by |
|-----|-------------|------|---------|-----|------|---------|
| `log.verbose` | Log more. | bool |  | `MINI_LOG_VERBOSE` | `--log-verbose` | every command |
